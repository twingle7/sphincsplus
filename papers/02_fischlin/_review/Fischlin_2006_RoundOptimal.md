# Round-Optimal Composable Blind Signatures in the Common Reference String Model

**出处**: CRYPTO 2006, LNCS Vol. 4117, pp. 60-77
**作者**: Marc Fischlin

## 论点
在公共参考串(CRS)模型下，基于一般复杂性假设构造轮次最优(两轮)且可并发执行的可组合盲签名方案。

## 背景
盲签名是匿名支付和隐私保护认证的核心原语。Lindell的下界表明三轮交互无法避免，但可通过CRS模型突破此限制。此前缺乏同时满足轮次最优、并发安全和UC安全的通用构造。

## 技术路线
引入单定理唯一非交互零知识证明(sUNIZK)作为核心技术工具。签名者通过NIZK证明对盲化消息的签名有效性，用户可在两轮交互中完成签名获取。进一步扩展该协议，在CRS模型下实现UC安全盲签名，支持安全协议组合。

## 核心成果
1. 首次构造轮次最优(两轮)盲签名方案，交互双方各发送一条消息
2. 首次形式化定义UC安全盲签名理想功能，实现可组合安全性
3. 核心安全仅依赖陷门置换和抗碰撞哈希等一般假设，无需随机预言机

## 与本项目关联
方法论参考: Fischlin框架是本项目盲签名协议的理论基础，其通用构造范式(Commit → NIZK证明)直接影响本项目的协议设计。
