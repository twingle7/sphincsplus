# Recommendation for Stateful Hash-Based Signature Schemes (NIST SP 800-208)

**出处**: NIST Special Publication 800-208, 2020
**作者**: David Cooper, Daniel Apon, Quynh Dang, Michael Davidson, Morris Dworkin, Carl Miller（NIST）

## 论点
NIST SP 800-208 正式批准 LMS/HSS 和 XMSS/XMSS^MT 两类有状态哈希签名方案作为美国国家标准，为后量子时代的长期安全提供保守的替代选择。

## 背景
在 NIST 后量子密码标准化项目完成之前，某些应用场景（如固件签名、代码签名）需要提前部署抗量子签名方案。有状态哈希签名方案基于最为保守的安全假设（仅依赖哈希函数安全性），且不需要等待 PQC 标准化完成即可部署——因为其安全性已被充分研究和验证。NIST 在 2020 年发布此推荐标准以满足这一紧急需求。

## 技术路线
SP 800-208 批准了两类方案：一是 LMS/HSS（基于 RFC 8554），二是 XMSS/XMSS^MT（基于 RFC 8391）。两类方案均基于 Winternitz 一次性签名和 Merkle 树认证结构。标准限定了具体的哈希函数（SHA-256 和 SHAKE256，192 或 256 位输出）和安全参数集。关键要求包括：密钥和签名生成必须在硬件密码模块中执行，且禁止导出私钥材料。同时，标准明确警示有状态方案不适合通用场景——状态管理失败将导致安全灾难。

## 核心成果
- 首个获批的抗量子数字签名美国国家标准
- 对 LMS/HSS 和 XMSS/XMSS^MT 的参数进行了官方裁剪和批准
- 为 NIST PQC 项目完成前的过渡期提供了合规的后量子签名选择

## 与本项目关联
**背景知识**: SP 800-208 的有状态方案与 SPHINCS+（无状态，FIPS 205）互补。本项目选择无状态 SPHINCS+ 作为底层方案，原因之一正是在盲签名协议中避免维护签名状态。SP 800-208 中关于硬件安全模块的要求对 Issuer 密钥管理有参考意义。
