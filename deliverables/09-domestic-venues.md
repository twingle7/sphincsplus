# 交付物 #9: 国内审稿渠道 — 期刊、会议与 Special Issue

## 1. 国内密码学/安全学术发表体系概述

国内后量子密码学领域的主要发表渠道分为三类：
- **中文核心期刊:** CCF A/B 级（或 T1/T2 级），审稿周期较长（6-18 个月）
- **密码学/安全学术会议:** 周期短（1-3 个月审稿），部分有正式论文集（LNCS/EI 收录）
- **Special Issue:** 时效性强，竞争相对较小，通常有特定征稿主题

### 2.1 《密码学报》(Journal of Cryptologic Research)

| **投稿渠道** | 官网在线投稿系统：[http://www.jcr.cacrnet.org.cn/journalx_mmxb/authorLogOn.action](http://www.jcr.cacrnet.org.cn/journalx_mmxb/authorLogOn.action) |

| **与本项目匹配度** | ⭐⭐⭐⭐⭐ |

**描述。** 《密码学报》是中国密码学会的官方旗舰期刊，是国内密码学领域影响最大、认可度最高的中文学术期刊。创刊仅十年即入选北大核心和 CCF T2 级，显示了其在学界的地位。对本文最关键的先例是——孙思维等人 2023 年在该刊发表了《SPHINCS+-SM3: 基于 SM3 的无状态数字签名算法》（Vol.10, No.6, pp.1266-1278），其贡献类型为"哈希替换 + 参数分析"，工程量低于本文。该先例强烈表明本文投《密码学报》有极大的接收概率。近年来该刊发表了大量后量子密码论文，包括胡磊 2025 年的后量子公钥密码综述、基于后量子密码的 TLS 1.3 性能评估等。双向匿名审稿，不收任何费用。主要缺点是审稿周期偏长且不可预测，6-12 个月的等待对时间敏感的投稿需权衡。

**曾接收的相似论文：**

1. **孙思维等, "SPHINCS+-SM3: 基于 SM3 的无状态数字签名算法"** (2023, Vol.10, No.6, pp.1266-1278) — 首次用 SM3 实例化 SPHINCS+ THF，哈希替换 + 参数分析，工程量低于本项目。[[DOI: 10.13868/j.cnki.jcr.000536](https://doi.org/10.13868/j.cnki.jcr.000536)]

2. **胡磊, "后量子公钥密码研究的问题与挑战"** (2025, Vol.12, No.2) — PQC 领域系统性综述，表明该刊对后量子密码方向持续关注。

**投稿策略：** 以中文撰写；强调 SPHINCS+ 的 NIST 标准化背景 + Poseidon2 的 ZK 友好性；增加与国密 SM3 的对比段落；引用 SPHINCS+-SM3 论文作为"同类工作的延续"来定位本文。

**投稿策略：** ⚠️ 仅当"论文发表时间不敏感 + 论文内容扩展为系统性工作"时才投。不推荐作为首选。

**投稿策略：** 中文或英文均可；如果有 ChinaCrypt 2026 的机会立即投稿；不论是否 CCF 都值得提交（审稿快、社交价值高）。

**投稿策略：** **最推荐的国内 CCF C 投稿目标。** Inscrypt 2027 预计 DDL 2027 年 5-7 月，时间充裕。

**描述。** CIHW 是国内信息隐藏与多媒体安全领域最高水平的学术平台。该会偏多媒体安全方向（隐写术、水印、深度伪造检测），**后量子密码不是其核心主题**。如果论文工作与信息隐藏/水印相结合（如基于格的隐写方案），才有投稿意义。国际层面的对应会议是 ACM IH&MMSec（CCF C 类）。对本项目不推荐。

**投稿策略：** 不推荐，除非论文涉及后量子密码与信息隐藏的交叉。

## 4. Special Issue 机会

### 4.1 《密码学报》后量子密码专题

**现状与机会：** 2023-2025 年间，《密码学报》已组织过多期"后量子密码"专题。下一篇专题可能在 2026-2027 年，主题可能扩展到"后量子隐私保护"或"后量子密码工程实现"。

**追踪渠道：** 关注《密码学报》官网征稿启事、中国密码学会微信公众号。Special issue 审稿周期通常比 regular issue 短（~3-6 个月）。

### 4.2 《信息安全学报》区块链安全专题

区块链安全是该刊的热门专题方向。如果本论文强调"区块链隐私 + 后量子盲签名"的交叉，可能符合征稿主题。

| 6 | FCS | B/T1 | — | 英文 | 40 天 | SCI Q1 + Fast Track |

### 组合投稿策略

**时间线敏感（希望在 2027 年 6 月前有接收通知）:**

```
方案 A: 先投 FC 2027 (DDL: 2026-09-17)
        → 如 12 月被拒 → Inscrypt 2027 (DDL: ~2027 年 5-7 月)
        → 如再被拒 → 《信息安全学报》(rolling submission)
        → 保证 2027 年中前有结果
```

**不敏感（以最高 CCF 等级为目标）:**

```
方案 B: 投《密码学报》(rolling submission)
        → 审稿周期 6-12 月
        → R&R 修改周期 1-3 月
        → 最终接收 2027 年中至年底
```

**双线并行（中英文两版稿件）:**

```
方案 C: 英文版 → FC 2027 或 Inscrypt 2027
        中文版 → 《密码学报》(加长版，更详细的中文技术描述)
        注意: 两版必须差异 >30% (避免一稿多投)
```

## 6. 国内审稿的特点与注意事项

1. **专家库小。** 国内密码学审稿人数量有限，主要来自中科院信工所、武汉大学、山东大学、上海交通大学、解放军信息工程大学等团队；ChinaCrypt 参会可提前认识审稿人。

2. **重视"国产化"适配。** 加一段"本文方法论同样适用于 SM3 替代 Poseidon2"会显著提升国内审稿人接受度。

3. **实验要求具体。** 确保包含：证明时间、验证时间、proof size、内存峰值、多方案对比表。

4. **引用国内工作。** 务必引用 SPHINCS+-SM3 等国内团队的工作，展示对国内社区了解。

### 中文 vs 英文投稿的权衡

| 维度 | 中文期刊 (密码学报) | 英文会议 (Inscrypt) |
|------|-------------------|-------------------|
| CCF 等级 | T2 (≈B 类) | C |
| 审稿周期 | 6-12 月 | 5-6 周 |
| 语言障碍 | 无 | 需要英文写作 |
| 学术圈影响 | 国内 | 国际 |
| 学位申请权重 | 高 | 中 |
| 引用可能性 | 低 (中文壁垒) | 高 (英文可得) |

## 7. 总结

**国内投稿的黄金组合:**

1. **首选:** Inscrypt 2027 (CCF C, 英文, LNCS, 国内举办, 审稿快)
2. **长线:** 《密码学报》(CCF T2, 中文, 审稿慢但有 SPHINCS+-SM3 先例)

```
           +

```
