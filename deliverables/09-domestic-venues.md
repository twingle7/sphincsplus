# 交付物 #9: 国内审稿渠道 — 期刊、会议与 Special Issue

## 1. 国内密码学/安全学术发表体系概述

国内后量子密码学领域的主要发表渠道分为三类：
- **中文核心期刊:** CCF A/B 级，审稿周期长（6-18 个月）
- **密码学/安全学术会议:** 周期短（1-3 个月审稿），部分有正式论文集（LNCS/EI 收录）
- **Special Issue:** 时效性强，竞争相对较小，通常有特定征稿主题

## 2. 中文核心期刊

### 2.1 《密码学报》(Journal of Cryptologic Research)

**基本信息:**
- CCF 等级: B（中文密码学领域最高级别期刊）
- 主办方: 中国密码学会
- 周期: 双月刊
- 格式: 中文，~15-20 页
- 审稿周期: 6-12 个月
- **投稿匹配项目:** ⭐⭐⭐⭐⭐

**已发表的直接相关论文（关键证据）:**

1. **孙思维等, "SPHINCS+-SM3: 基于SM3的无状态数字签名算法" (2023, Vol. 10, No. 6, pp. 1266-1278)**
   - 这是最直接的证据——《密码学报》发表了 SPHINCS+ 替换哈希的工作
   - 该文的贡献类型是"哈希替换+参数分析"，工程量低于本项目
   - **结论:** 本项目的复杂度高于该文，投《密码学报》有极大的接受概率

2. **历年《密码学报》发表的后量子主题论文涉及:**
   - 格基密码方案的优化实现
   - 后量子签名方案的参数选择
   - 国密算法（SM2/SM3/SM4）的后量子适配
   - 零知识证明系统的设计

**投稿策略:**
- 必须以中文撰写（杂志语言为中文）
- 强调 SPHINCS+ 的 NIST 标准化背景 + Poseidon2 的 ZK 友好性
- 增加与 SM3/国密对比的段落（国内审稿人重视国产化适配）
- 可引用 SPHINCS+-SM3 论文作为"延续性工作"来定位本文

### 2.2 《软件学报》(Journal of Software)

**基本信息:**
- CCF 等级: A（中文计算机科学领域最高级别之一）
- 主办方: 中国科学院软件研究所
- 周期: 月刊
- 审稿周期: 12-18 个月（非常长）
- 格式: 中文，~20-30 页（要求全面性）

**接收主题:**
- 软件/系统安全
- 密码学协议的形式化验证
- 区块链技术与应用
- 零知识证明系统

**投稿策略:** ⚠️ 审稿周期过长，仅当"论文发表时间不敏感"时才投。

### 2.3 《计算机学报》(Chinese Journal of Computers)

**基本信息:**
- CCF 等级: A
- 主办方: 中国科学院计算技术研究所
- 周期: 月刊
- 审稿周期: 12-18 个月

**接收主题:**
- 信息安全与密码学
- 区块链
- 新型计算架构

**与本项目匹配度:** ⭐⭐⭐（该刊偏好系统性工作，单方案实现可能被认为贡献不足）

### 2.4 《信息安全学报》(Journal of Information Security)

**基本信息:**
- CCF 等级: 未收录（中科院主办的新刊）
- 周期: 双月刊
- 审稿周期: 3-9 个月（比上述两刊快）
- 格式: 中文

**优势:**
- 审稿周期短
- 对工程实现类论文容忍度高
- 后量子安全是其常设栏目

**投稿策略:** 时间敏感的推荐选择。

## 3. 国内学术会议

### 3.1 中国密码学会年会 (ChinaCrypt)

**基本信息:**
- CCF 等级: 无（国内最高级别密码学会议）
- 频率: 每年一届 (通常在 10-11 月)
- 格式: 中文/英文，~8-12 页
- 审稿周期: 2-3 个月
- 论文集: 部分年份有 LNCS proceedings (EI 收录)
- **投稿匹配项目:** ⭐⭐⭐⭐⭐

**特点:**
- 国内密码学学术圈的核心会议
- 接收密码学实现、工程化、协议设计等类型的论文
- 近年设有"后量子密码"专题 track
- 与会者包括密码学报编委、国家密码管理局专家——**是建立学术联系的最佳场合**

**投稿策略:**
1. 中文或英文均可（建议中文初稿 + 英文图表）
2. 如果有 ChinaCrypt 2026 的机会（2026 年 10-11 月），现在（7 月）投稿时间紧迫但可行
3. 如果没有赶上 2026，瞄准 ChinaCrypt 2027

### 3.2 Inscrypt (International Conference on Information Security and Cryptology)

**基本信息:**
- CCF 等级: C
- 频率: 每年一届，**在中国举办**（中国密码学会承办）
- 格式: LNCS (Springer), 12-20 页, 英文
- 审稿周期: 3-4 个月
- 接收率: ~30-35%
- **投稿匹配项目:** ⭐⭐⭐⭐⭐

**关键优势:**
1. **CCF C** — 有官方认定的 CCF 等级，可用于学术业绩
2. **LNCS 出版** — Springer LNCS 系列，EI/CPCI 索引
3. **在中国举办** — 无需差旅费到国外参会
4. **英文撰写** — 可以直接使用国际投稿版本，无需翻译成中文
5. **接收范围广** — 密码学实现、系统安全、区块链隐私等均在 scope 内

**历年接收论文类型:**
- 密码学方案实现和性能优化
- 后量子密码学
- 零知识证明系统
- 隐私保护技术
- 区块链安全

**投稿策略:** **这是最推荐的国内 CCF C 投稿目标。** Inscrypt 的 CCF C 等级满足"CCF 推荐会议"的硬性要求，同时竞争比 FC/ACISP 等竞争性 C 会小。

### 3.3 全国信息隐藏暨多媒体安全学术大会 (CIHW)

**基本信息:**
- CCF 等级: 未收录
- 频率: 每年一届
- 论文集: 部分年份有 EI 收录

**与本项目匹配度:** ⭐⭐（偏多媒体安全，非密码学协议）

## 4. Special Issue 机会

### 4.1 《密码学报》后量子密码专题

**现状:**
- 2023-2025 年间，《密码学报》已组织过多期"后量子密码"专题
- **机会:** 下一篇专题可能在 2026-2027 年，主题可能扩展到"后量子隐私保护"或"后量子密码工程实现"
- Guest Editor 通常是国内后量子密码学的领军学者（如中国科学院、武汉大学、山东大学的密码学团队）

**如何追踪:**
- 关注《密码学报》官网的"征稿启事"
- 关注中国密码学会微信公众号
- Special issue 的审稿周期通常比 regular issue 短（~3-6 个月）

### 4.2 《信息安全学报》区块链安全专题

区块链安全是该刊的热门专题方向。如果本论文强调"区块链隐私 + 后量子盲签名"的交叉，可能符合征稿主题。

### 4.3 Frontiers of Computer Science (FCS) — "Blockchain and Post-Quantum Security" Special Issue

FCS (CCF B, Springer, 英文) 偶尔组织区块链安全和后量子密码学专题。英文期刊，审稿周期 3-6 个月。值得关注。

## 5. 国内投稿策略总结

### 推荐优先级

| 优先级 | 目标 | CCF | 语言 | 审稿周期 | 理由 |
|--------|------|-----|------|---------|------|
| **1** | **Inscrypt 2027** | C | 英文 | 3-4月 | CCF C + LNCS + 国内举办 + 收稿范围匹配 |
| **2** | **《密码学报》** | B | 中文 | 6-12月 | 最高级别中文密码学刊 + 有直接先例(SPHINCS+-SM3) |
| **3** | **ChinaCrypt 2026/2027** | - | 中/英 | 2-3月 | 国内密码学核心会议 + 学术社交价值 |
| 4 | FC 2027 | C | 英文 | 4-6月 | 国际金融密码学顶会 (详见 #8) |
| 5 | 《信息安全学报》 | - | 中文 | 3-9月 | 时间敏感的最佳中文保底 |

### 组合投稿策略

**时间线敏感（希望在 2027 年 6 月前有接收通知）:**

```
方案 A: 先投 FC 2027 (deadline: 2026-09)
        → 如 12 月被拒，改投 Inscrypt 2027 (deadline: ~2027 年 3 月)
        → 如再被拒，投《信息安全学报》(rolling submission)
        → 保证 2027 年中有结果
```

**不敏感（以最高 CCF 等级为目标）:**

```
方案 B: 投《密码学报》(current submission)
        → 审稿周期 6-12 月
        → 如果要求修改 (Revise & Resubmit)，修改周期 1-3 月
        → 最终接收 2027 年中至年底
```

**双线并行（中英文两版稿件）:**

```
方案 C: 英文版 → FC 2027 或 Inscrypt 2027
        中文版 → 《密码学报》(加长版，更详细的中文技术描述)
        注意: 两版必须差异 >30% (避免一稿多投)
        英文版偏"工程实现+区块链场景"
        中文版偏"Poseidon2 THF适配+SPHINCS+参数选择"
```

### 学位申请的 CCF 等级要求

如果投稿是为满足学位申请的 CCF 论文发表要求：

| 要求 | 推荐投稿 |
|------|---------|
| 至少 1 篇 CCF C | Inscrypt 或 FC |
| 至少 1 篇 CCF B | 《密码学报》或 ACISP |
| 至少 1 篇 CCF A | 极难——建议先发 B 或 C，再冲 A |

## 6. 国内审稿的特点与注意事项

### 6.1 中文期刊审稿特点

1. **专家库小:** 国内密码学领域的审稿人数量有限（全国可能不到 50 位活跃审稿人）。你的审稿人很可能来自以下团队之一：中国科学院信息工程研究所、武汉大学、山东大学、上海交通大学、解放军信息工程大学。这些团队的成员常在 ChinaCrypt 出任 PC——**参会可以提前认识审稿人**。

2. **重视"国产化"适配:** 如果你能加一段"Poseidon2 的 SM3 替代方案"或"国密合规的哈希-证明共设计"，会显著提升国内审稿人的接受度。即使不是论文核心贡献，提到"本文的方法论同样适用于 SM3 替代 Poseidon2，为国产密码标准的 Fischlin 实例化提供技术路径"也会加分。

3. **实验要求具体:** 国内审稿人偏好具体的性能数据。确保论文包含：证明时间、验证时间、proof size、内存峰值、与其他方案的对比表。

4. **引用国内工作:** 务必引用 SPHINCS+-SM3 [《密码学报》2023] 和其他国内密码学团队的工作。这显示对国内学术社区的了解。

### 6.2 中文 vs 英文投稿的权衡

| 维度 | 中文期刊 (密码学报) | 英文会议 (Inscrypt) |
|------|-------------------|-------------------|
| CCF 等级 | B | C |
| 审稿周期 | 6-12 月 | 3-4 月 |
| 语言障碍 | 无 | 需要英文写作 |
| 学术圈影响 | 国内 | 国际 |
| 学位申请权重 | 高 (B 类) | 中 (C 类) |
| 引用可能性 | 低 (中文壁垒) | 高 (英文可得) |

**建议:** 如果学位申请对 CCF B 有硬性要求，优先投《密码学报》。如果时间敏感，投 Inscrypt 更稳妥。

## 7. 总结

**国内投稿的黄金组合:**
1. **首选:** Inscrypt 2027 (CCF C, 英文, LNCS, 国内举办, 审稿快)
2. **长线:** 《密码学报》(CCF B, 中文, 审稿慢但有 SPHINCS+-SM3 先例)
3. **社交:** ChinaCrypt 2026/2027 (非 CCF 但学术社交价值高)
4. **保底:** 《信息安全学报》(审稿快的新刊)

结合 #8 的区块链会议分析，**最佳整体策略是:**

```
FC 2027 (英文, CCF C) → 如拒 → Inscrypt 2027 (英文, CCF C)
           +
《密码学报》(中文版, CCF B) — 与英文版并行投稿（差异化 >30%）
```
