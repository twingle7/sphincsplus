# ACISP — 相关论文（4篇）

## 1. Lattice Blind Signatures with Forward Security ⭐ (Best Paper Award)
- **作者**: Huy Quoc Le, Dung Hoang Duong, Willy Susilo 等
- **年份**: 2020, 25th ACISP
- **Free PDF**: arXiv:2007.06884
- **与本项目关联**: 首个前向安全盲签名方案，基于SIS假设。ACISP 2020最佳论文奖。

## 2. On Lattice-Based Interactive Protocols: BLAZE+
- **作者**: Nabil Alkeilani Alkadri, Rachid El Bansarkhani, Johannes Buchmann
- **年份**: 2020, 25th ACISP
- **与本项目关联**: 改进BLAZE格盲签名方案，减少aborts。

## 3. Quantum-access Security of Hash-based Signature Schemes
- **年份**: 2023, 28th ACISP
- **与本项目关联**: 哈希签名（含SPHINCS+）在量子查询攻击下的安全性分析。

## 4. Tightly Secure Lattice Identity-Based Signature in the QROM
- **年份**: 2023, 28th ACISP
- **与本项目关联**: QROM中紧致安全的格基身份签名。
