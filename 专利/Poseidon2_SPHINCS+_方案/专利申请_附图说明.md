# 专利申请附图说明

## 图1：整体协议流程图

本图展示本发明方法的五个阶段完整交互流程：

```
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│   Holder     │         │   Issuer     │         │  Verifier    │
│  (持有者)    │         │  (签发者)    │         │  (验证者)    │
└──────┬───────┘         └──────┬───────┘         └──────┬───────┘
       │                        │                        │
       │ ① c = Com(m_pub; r)   │                        │
       │───────────────────────►│                        │
       │                        │                        │
       │                        │ ② σ_blind =           │
       │                        │   Sign(sk_sig, c)     │
       │ ③ σ_blind              │                        │
       │◄───────────────────────│                        │
       │                        │                        │
       │ ④ σ = Unblind(σ_blind) │                       │
       │    σ_C = Enc(pk_E,     │                        │
       │      c||σ; ω2)         │                        │
       │    π_F = Prove(        │                        │
       │      pk_sig, pk_E,     │                        │
       │      c, σ_C, w)        │                        │
       │                        │                        │
       │ ⑤ Σ = (σ_C, π_F)       │                        │
       │────────────────────────┼───────────────────────►│
       │                        │                        │
       │                        │     ⑥ Verify(pk_sig,   │
       │                        │        pk_E, m_pub,    │
       │                        │        σ_C, π_F)       │
       │                        │        → {0,1}         │
```

- 步骤①（Commit阶段）：持有者选择随机数r，计算承诺c = Poseidon2_Sponge(m_pub || r)，通过安全信道发送至签发者
- 步骤②（Issue阶段）：签发者使用SPHINCS+私钥对承诺c签名，生成σ_blind
- 步骤③：签发者将σ_blind返回给持有者
- 步骤④（Finalize + Show阶段）：持有者解盲得到σ，构造密文σ_C，生成展示证明π_F（核心创新步骤）
- 步骤⑤：持有者将展示证明Σ = (σ_C, π_F)发送给验证者
- 步骤⑥（Verify阶段）：验证者基于仅有的公共参数验证π_F的有效性
