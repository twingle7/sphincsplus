# 摘要

本发明公开了一种基于全内生AIR的哈希后量子签名盲签名方法及系统，属于密码学技术领域。方法包括：持有者利用Poseidon2海绵哈希函数生成承诺c并发送至签发者；签发者利用SPHINCS+（FIPS 205）、XMSS（SP 800-208）或XMSS^MT/HSS私钥对承诺签名生成盲签名σ_blind；持有者解盲得到最终签名σ并构造密文σ_C；持有者通过执行跟踪构建器模拟签名验证的完整执行路径，将全部哈希运算展开为Poseidon2置换序列并逐轮记录中间状态，在每轮置换后调用Poseidon2单轮计算函数预计算下一轮状态的期望值并存入跟踪辅助列，基于仅含等值约束（度数为1）的全内生AIR生成STARK展示证明π_F；验证者接收证明并验证。本发明将签名验证的全部密码学运算内生地纳入执行跟踪，通过预计算期望状态将AIR约束简化为等值检查，无需可信设置，安全假设仅依赖哈希函数抗碰撞性，适配多种NIST标准化哈希后量子签名方案。128-bit安全级下证明体积约85 KB，验证时间约4毫秒。

## 英文摘要（Abstract）

The present invention discloses a hash-based post-quantum signature blind signature method and system based on full endogenous AIR, belonging to the field of cryptography. The method comprises: a holder generates a commitment c using a Poseidon2 sponge hash function and sends it to an issuer; the issuer signs the commitment using an SPHINCS+ (FIPS 205), XMSS (SP 800-208), or XMSS^MT/HSS private key to generate a blind signature σ_blind; the holder unblinds to obtain a final signature σ and constructs a ciphertext σ_C; the holder simulates the complete execution path of signature verification through a trace builder, expanding all hash operations into Poseidon2 permutation sequences and recording intermediate states round by round, calls a Poseidon2 single-round computation function after each round to pre-compute expected next-round state values and stores them in auxiliary trace columns, and generates a STARK show proof π_F based on a full endogenous AIR containing only equality constraints (degree 1); a verifier receives and verifies the proof. The present invention endogenously incorporates all cryptographic operations of signature verification into the execution trace, simplifies AIR constraints to equality checks through pre-computed expected states, requires no trusted setup, relies only on hash function collision resistance as the security assumption, and adapts to multiple NIST-standardized hash-based post-quantum signature schemes. At 128-bit security level, proof size is approximately 85 KB and verification time is approximately 4 ms.
